# Anke Sports 扩展隐私说明草案

> 已取消（2026-09-13）：Chrome扩展不再实施或发布，本草案仅作历史记录，不是当前产品隐私政策或商店材料。

更新：2026-09-09。此文档描述当前本地实现；正式服务地址、运营主体、联系邮箱、服务端保留政策和生效日期尚待确定，因此尚不能作为商店已发布的隐私政策。

连接账号后，扩展从 Anke Sports 服务读取账号标识、显示名称、时区、关注匹配的赛程和比赛链接。用户主动按「读取当前视频」时，它仅取得当前 YouTube 视频的 URL 和标签标题；不读取页面正文、观看记录、Cookie、音视频或其他标签内容。URL 会清除跟踪参数。用户确认比赛和类型并保存时，该 URL、标题、比赛标识、类型和幂等请求标识被发送至其连接的 Anke Sports 服务，用于维护个人比赛链接与订阅源。

账号凭证、赛程缓存和草稿只保存在浏览器会话内；关闭弹窗不会清除，关闭整个浏览器、重载或停用扩展会清除。草稿额外在24小时后失效。公共应用注册标识及界面筛选设置保存在本机，不通过 Chrome 同步。退出会尝试撤销服务器连接并清除本机账号数据；如果撤销结果未知，界面会提示在网页设置中处理。仅卸载扩展不删除服务端已经保存的比赛链接或撤销连接，需在 Anke Sports 网页中管理。

当前扩展没有广告、分析埋点、远程执行代码、浏览历史扫描或售卖数据功能。扩展不把视频内容发送给 AI 服务，不向 YouTube 发送 API 请求。身份与日历请求仅发往构建时配置的 Anke Sports 服务；正式 HTTPS 部署和云端日志保留需要在上线前另行验证。

已保存链接、关注和账号数据的删除通过 Anke Sports 网页提供的管理流程执行。正式发布前必须填入真实运营联系方式、对齐服务端删除/备份保留周期，并托管可公开访问的政策页面；这些内容当前未被虚构为已配置。
