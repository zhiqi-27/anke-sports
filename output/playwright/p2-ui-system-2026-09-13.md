# P2 UI system verification

Date: 2026-09-13 (Asia/Shanghai)

## Scope

- Consolidated colour, typography, spacing, radius, rule, layer and motion values into root `tokens.css`.
- Applied graphite canvas/surface/raised levels and acid-lime action emphasis across all four runtime stylesheets.
- Replaced the two equal subscription platform cards with a compact two-row instruction list.
- Replaced repeated route slogans with task labels and kept only copy that explains a constraint or next action.
- Removed the remaining Chrome-extension wording from the active connection-management UI.

## Static verification

- `npm run typecheck`: passed.
- `npm run build`: passed; all application routes prerendered.
- `git diff --check`: passed.
- Runtime stylesheets contain no literal hex, RGB or OKLCH colours; colour literals live only in `tokens.css`.
- Runtime stylesheets contain no raw positive-pixel `gap`, `padding`, `margin`, `border-radius` or motion duration values.
- No `transition-all`, bounce easing, decorative gradient, mixed icon library or pure black/white base colour was introduced.

- no document-level horizontal overflow;
- `/calendar`, `/following`, `/creators`, `/subscription` and `/settings` rendered without an application error;
- subscription guide contains two `.subscription-guide-row` elements and zero legacy `.guide-card` elements;
- route headings use the compressed task labels;
- first keyboard Tab focuses “跳到主要内容” with a visible 2 px inner ring and 4 px outer ring;
