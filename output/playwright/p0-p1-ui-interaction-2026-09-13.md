# P0/P1 UI 与交互本地验收 · 2026-09-13

## 边界

- 验收对象：客户端工作树中的未提交 P0/P1 改动。
- 浏览器：Playwright Chromium，`127.0.0.1:3000`。
- 公共赛程读取通过本地 Next 代理访问现有开发服务，只做 GET。
- 登录态与 173 条待确认视频使用浏览器网络 mock；批量操作命中 mock POST，没有修改真实账号或生产数据。
- 本轮没有 push、部署或正式环境变更。

## 结果

- 认证恢复：`/me/calendar` 延迟 500ms 时，只显示“正在准备你的体育日历”；延迟结束前不出现游客登录入口，结束后再显示登录态。
- 周视图首屏：当前周最早比赛为 00:30，周视图滚动容器 `scrollTop=0`；不再固定停在 07:00 后方。
- 大队列：173 条数据只渲染 20 张卡片、分 9 页；本页按 8 场比赛分组。
- 筛选：搜索“待确认视频 173”后只渲染对应 1 张卡片，并隐藏不需要的分页。
- 批量处理：选择本页后显示 20 项已选并启用两个批量按钮；批量确认发出 20 个对应 review POST，均收到 mock 200。
- 账号安全：点击账号行打开账号面板，不会立即退出；关闭后焦点回到账号按钮。
- 键盘：从页面起点按 Tab，首个焦点是“跳到主要内容”。侧栏关注摘要不再产生重复链接焦点。
- 公共日历：能力检查期间不显示来源选择器；服务返回 `DOCUMENT_FEATURE_UNAVAILABLE` 后只显示“公共日历尚未开放”。
- 尺寸：1280×800 下月视图事件高 28px，时间与标题 12px；图标按钮 44×44px；日程时间 24px；详情主时间 40px。
- 动效：Modal 与 Drawer 关闭后先进入 `is-closing`，200ms 后卸载；`prefers-reduced-motion` 下按钮过渡为 0ms，弹层保留短透明度反馈而不做位移/缩放。
